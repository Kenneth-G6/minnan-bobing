## 4. 结论

- **终局掷骰次数**：100 局平均 **223.3 掷**（中位 214，四分位区间 164–260，标准差 80.3），折合 4 人约 **56.2 轮**。极差 467 掷，说明「手气周期」造成的波动远大于规则本身。
- **终局由最慢的清池项决定**：每局发奖 62.91 件（62 个普通奖 + 状元），而全部掷骰中仅 60.33% 有效、39.67% 是「池已满、空手而归」——中后段大部分掷骰已经在做无效功。
- **100 局样本下的座位偏差**：4 位玩家每局奖品数均值 P1 16.110、P2 15.830、P3 15.430、P4 15.540，公平期望 15.727，最大 |z| = 1.74（Bonferroni 阈值 2.50）→ **未达显著**——这个样本量（每局每人的标准误约 0.220 件）还不足以判定先手效应是否存在。
- **把样本放大到 10000 局，座位梯度严格单调地显现**：P1 15.993（1.70%，z = +11.89）、P2 15.829（0.66%，z = +4.58）、P3 15.602（-0.79%，z = -5.52）、P4 15.479（-1.57%，z = -11.12）。首末位差距 0.514 件/局，相对公平值 3.27%——**先手优势真实存在，但量级极小**。
- **偏差在奖项间的分布**（10000 局复核的四人极差 / 最大 |z|）：一秀 0.294 件 / |z| 7.78；二举 0.140 件 / |z| 4.86；四进 0.047 件 / |z| 2.12；三红 0.055 件 / |z| 3.37；对堂 0.023 件 / |z| 2.14；状元 0.012 件 / |z| 1.84。一秀池最大、清空最早，偏差也最明显；**状元是「大小更替制」而不是先到先得的额度争夺，没有可抢的池子，偏差最小**。机制上：轮转掷骰使每人累计掷骰数最多只差 1 次，池子清空得越早，这 1 次之差被放大的比例就越高；再加上「先手手气好 → 池子更早满 → 后手机会更少」的正反馈，就形成了这条细微却稳定的顺次梯度。
- **随机性**：1,000,000 次掷骰的判定分布与穷举理论值吻合，χ² = 10.18（df = 12，p = 0.600）；骰子六面频率 χ² = 4.23（df = 5，p = 0.517）；对局内 22,333 次判定 χ² = 10.73（p = 0.552）。随机源未发现可察觉偏差。
